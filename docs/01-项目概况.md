# 项目概况

## 基本信息

| 项目 | 说明 |
|------|------|
| **名称** | FGO 因陀罗桌面宠物（Indra Desktop Pet） |
| **类型** | 同人桌面宠物 + LLM 陪伴应用 |

| **语言** | Python 3.10+ |
| **入口** | `python src/main.py` |

## 产品定位

以《Fate/Grand Order》中 Lancer **因陀罗（Indra）** 为形象，结合大语言模型与 RAG 知识库，在桌面上提供：

- **文字陪伴**：双击立绘打开聊天，以神王口吻对话；
- **屏幕吐槽**：定时截图 → 视觉模型描述 → LLM 发表评论；
- **设定一致**：内置摩诃婆罗多、FGO 剧情等 lore，以及语气 style 样本，检索后注入上下文。

目标用户：熟悉 FGO / 印度神话的同好，能自行配置 LLM 与视觉 API。

## 核心特性（摘要）

| 特性 | 说明 |
|------|------|
| 透明桌宠窗口 | 无边框、置顶、可拖拽与滚轮缩放 |
| 系统托盘 | 显示/隐藏、设置、屏幕监视开关、长期记忆开关 |
| LLM 对话 | OpenAI 兼容 API（DeepSeek、SiliconFlow 等） |
| RAG 双索引 | lore（设定/剧情）+ style（语气） |
| 本地嵌入 | `gte-multilingual-base` 离线向量检索 |
| 长期记忆 | SQLite + 向量，可选开关，混合评分检索 |
| 情绪表情 | 回复解析 emotion 后切换 Emoji |
| 屏幕观察 | mss 截图 + Qwen-VL 描述 + LLM 评论气泡 |

## 仓库目录结构

```
Indra_Desktop_Pet/
├── assets/                 # 立绘、图标、动画帧、表情图
├── config/                 # settings.json、user_memory.db（运行时）
├── docs/                   # 项目文档（本目录）
├── models/                 # 本地嵌入模型 gte-multilingual-base
├── screenshots/            # 屏幕观察临时截图（gitignore 部分规则）
├── src/
│   ├── main.py             # 程序入口
│   ├── settings_manager.py # 配置单例 + 开发环境 .env 加载
│   ├── utils.py            # 资源路径、ResourceManager
│   ├── gui/                # PySide6 界面：桌宠、托盘、设置、气泡
│   ├── llm/                # 对话、RAG、长期记忆、人设
│   ├── vision/             # 截图、视觉 API
│   └── workers/            # 屏幕观察后台线程
├── .env.example            # 开发环境 API 配置模板（可提交 Git）
├── .env                    # 本地密钥（不提交，见 .gitignore）
├── FGO因陀罗桌宠.spec      # PyInstaller 打包配置
└── README.md               # 用户向说明
```
