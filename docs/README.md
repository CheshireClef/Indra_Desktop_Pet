## 快速上手（开发者）

```bash
# 1. 创建虚拟环境并安装依赖（见 02-技术要点.md）
# 2. 复制 .env.example 为 .env 并填入 API Key（见 05-开发环境配置.md）
cp .env.example .env   # Windows 可手动复制

# 3. 启动
python src/main.py
```

## 文档维护约定

- 实现重要功能后，同步更新 **04-开发进度** 与 **08-实现计划**。
- 新增配置项或数据表字段时，同步更新 **07-数据结构**。
- 产品方向变更时，先改 **06-产品需求(PRD)**，再落到实现计划与进度。
