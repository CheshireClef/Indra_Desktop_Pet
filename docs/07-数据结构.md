# 数据结构说明

> 从根目录 `BACKEND_STRUCTURE.md` 迁入。描述配置 schema 与知识库文件约定，不涉及 LlamaIndex 内部索引格式。

## 1. 配置结构：config/settings.json

由 `src/settings_manager.py` 读写；缺失键从 `DEFAULTS` 合并。

### 1.1 顶层键

| 顶层键 | 类型 | 说明 |
|--------|------|------|
| `pet` | object | 桌宠外观 |
| `behavior` | object | 交互与定时行为 |
| `user` | object | 用户展示信息 |
| `llm` | object | 对话 LLM API |
| `vision` | object | 视觉 API 与截图行为 |

### 1.2 pet

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `name` | string | 桌宠名称 | `"因陀罗"` |
| `scale` | number | 立绘缩放 | `1.0` |
| `initial_position` | string | 初始位置 | `"bottom-right"` |
| `font_size` | number | 聊天/气泡字体 | `13` |

### 1.3 behavior

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `idle_interval_s` | number | 闲置判定间隔（秒） | `7` |
| `screen_watch_enabled` | boolean | 屏幕观察开关 | `false` |
| `screen_watch_interval_s` | number | 观察间隔（秒） | `60` |
| `temp_bubble_duration_s` | number | 临时气泡时长（秒） | `8` |
| `long_term_memory_enabled` | boolean | 长期记忆开关 | `false` |

### 1.4 user

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `display_name` | string | 用户称呼 | `"主人"` |

### 1.5 llm

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `provider` | string | openai / deepseek / custom | `"openai"` |
| `api_key` | string | API Key | `""` |
| `base_url` | string | API 根 URL | 见代码 |
| `model` | string | 模型名 | `"gpt-4o-mini"` |
| `temperature` | number | 采样温度 | `1.0` |
| `max_tokens` | number | 最大 token | `512` |
| `history_rounds` | number | 历史轮数 | 默认 6 |

开发环境下，`api_key`、`base_url`、`model`、`provider` 可被 `.env` 覆盖（见 [05-开发环境配置](./05-开发环境配置.md)）。

### 1.6 vision

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `api_url` | string | 视觉 API URL | SiliconFlow 默认 |
| `api_key` | string | API Key | `""` |
| `enabled` | boolean | 视觉能力开关 | `false` |
| `auto_interval` | number | 预留 | `0` |
| `keep_last_n_screenshots` | number | 保留截图数 | `3` |
| `model` | string | 视觉模型 | `Qwen/Qwen3-VL-32B-Instruct` |

## 2. 知识库：src/llm/knowledge/

### 2.1 lore（设定与剧情）

- **路径**：`src/llm/knowledge/lore/`
- **子目录**：`maha_vol_01`～`06`、`fgo剧情总结/` 等
- **文件**：`story_XXX.txt` + 可选 `story_XXX.facts.json`
- **facts.json**：JSON 数组，元素含 `extraction_text`、`attributes` 等
- **分块**：chunk_size=800, overlap=200

### 2.2 style（语气）

- **路径**：`src/llm/knowledge/style/`
- **内容**：剧情对话、语音文本脱水版
- **分块**：chunk_size=300, overlap=50

索引持久化在 `src/llm/knowledge_db/`，按文件 manifest 增量更新。

## 3. 长期记忆：config/user_memory.db

### 3.1 表 memories

| 列名 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 主键 |
| `content` | TEXT | 记忆正文 |
| `embedding` | BLOB | content 向量 |
| `created_at` | TEXT | ISO 时间 |
| `updated_at` | TEXT | ISO 时间 |
| `topic` | TEXT | 主题词 |
| `topic_embedding` | BLOB | topic 向量 |

### 3.2 检索与合并

- **混合评分**：`score = 1.2×语义相似度 + 0.3×时间衰减`（半衰期 30 天）
- **去重**：content 相似度 > 0.92 则更新
- **合并**：同 topic 簇达 5 的倍数时 LLM 合并，保留最早 `created_at`
