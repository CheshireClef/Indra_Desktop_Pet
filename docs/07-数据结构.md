# 数据结构说明

> 从根目录 `BACKEND_STRUCTURE.md` 迁入。描述配置 schema 与知识库文件约定，不涉及 LlamaIndex 内部索引格式。

## 1. 配置结构：config/settings.json

由 `src/settings_manager.py` 读写；缺失键从 `DEFAULTS` 合并。

### 1.1 顶层键

| 顶层键 | 类型 | 说明 |
|--------|------|------|
| `pet` | object | 桌宠外观 |
| `behavior` | object | 交互与定时行为 |
| `user` | object | 用户展示信息 |
| `llm` | object | 对话 LLM API（**legacy 投影**，与 `models` 同步） |
| `vision` | object | 视觉 API（**legacy 投影**） |
| `models` | object | **v2 单一真相源**：连接、对话/识图模型、能力缓存 |

### 1.2 pet

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `name` | string | 桌宠名称 | `"因陀罗"` |
| `scale` | number | 立绘缩放 | `1.0` |
| `initial_position` | string | 初始位置 | `"bottom-right"` |
| `font_size` | number | 聊天/气泡字体 | `13` |

### 1.3 behavior

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `idle_interval_s` | number | 闲置判定间隔（秒） | `7` |
| `screen_watch_enabled` | boolean | 屏幕观察开关 | `false` |
| `screen_watch_interval_s` | number | 观察间隔（秒） | `60` |
| `temp_bubble_duration_s` | number | 临时气泡时长（秒） | `8` |
| `long_term_memory_enabled` | boolean | 长期记忆开关 | `false` |
| `show_reasoning_in_chat` | boolean | 聊天窗口折叠展示 API 思考链 | `true` |

### 1.4 user

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `display_name` | string | 用户称呼 | `"主人"` |

### 1.5 llm

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `provider` | string | openai / deepseek / custom | `"openai"` |
| `api_key` | string | API Key | `""` |
| `base_url` | string | API 根 URL | 见代码 |
| `model` | string | 模型名 | `"gpt-4o-mini"` |
| `temperature` | number | 采样温度 | `1.0` |
| `max_tokens` | number | 最大 token | `512` |
| `history_rounds` | number | 历史轮数 | 默认 6 |
| `max_reply_chars` | number | 聊天 reply 最大字符（超长截断） | `800` |

开发环境下，对话/识图 API 可由 `.env` 注入 `models`（`MODELS_*` 或 `LLM_*` / `VISION_*`）；独立识图连接对应 `connections.vision`（见 [05-开发环境配置](./05-开发环境配置.md)）。

### 1.6 vision

| 字段 | 类型 | 含义 | 默认值 |
|------|------|------|--------|
| `api_url` | string | 视觉 API URL | SiliconFlow 默认 |
| `api_key` | string | API Key | `""` |
| `enabled` | boolean | 视觉能力开关 | `false` |
| `auto_interval` | number | 预留 | `0` |
| `keep_last_n_screenshots` | number | 保留截图数 | `3` |
| `model` | string | 视觉模型 | `Qwen/Qwen3-VL-32B-Instruct` |

### 1.7 models（schema_version: 2）

| 路径 | 类型 | 含义 |
|------|------|------|
| `models.schema_version` | number | 固定 `2` |
| `models.connections[]` | array | API 连接：`id`（`default` 对话、`vision` 识图、`memory` 记忆录入/整理）、`vendor`、`protocol`、`base_url`、`api_key` |
| `models.chat` | object | `connection_id`（通常 `default`）、`model`、`temperature`、`max_tokens`、`history_rounds`、`output_mode` |
| `models.vision` | object | `same_connection_as_chat`、`connection_id`（共用为 `default`，独立为 `vision`）、`model` |
| `models.memory` | object | `same_connection_as_chat`、`connection_id`、`model`（空则回退 chat.model）、`temperature`、`max_tokens`、`extract_context_rounds`（1–5） |
| `models.capabilities_cache` | object | 键 `{connection_id}:{model_id}` → `json_mode`、`supports_vision`、`probed_at`、可选 `vision_hints`（探测成功的识图参数）、`probe_note`（失败摘要） |

`chat.output_mode`：`auto` | `json_preferred` | `natural_only`

`capabilities_cache.*.json_mode`：`response_format` | `prompt_only` | `natural_only`

Vendor 预置表见 `src/llm/providers/registry.json`（含 siliconflow、deepseek、minimax、ollama 等）。

启动时若仅有 `llm`/`vision`，`SettingsManager._migrate_models_v2()` 自动迁移并写回。

## 2. 知识库：src/llm/knowledge/

### 2.1 lore（设定与剧情）

- **路径**：`src/llm/knowledge/lore/`
- **子目录**：`maha_vol_01`～`06`、`fgo剧情总结/` 等
- **文件**：`story_XXX.txt` + 可选 `story_XXX.facts.json`
- **facts.json**：JSON 数组，元素含 `extraction_text`、`attributes` 等
- **分块**：chunk_size=800, overlap=200

### 2.2 style（语气）

- **路径**：`src/llm/knowledge/style/`
- **内容**：剧情对话、语音文本脱水版
- **分块**：chunk_size=300, overlap=50

索引持久化在 `src/llm/knowledge_db/`，按文件 manifest 增量更新。

## 3. 长期记忆：config/user_memory.db

### 3.1 表 memories

| 列名 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 主键 |
| `content` | TEXT | 记忆正文 |
| `embedding` | BLOB | content 向量 |
| `created_at` | TEXT | ISO 时间 |
| `updated_at` | TEXT | ISO 时间 |
| `topic` | TEXT | 主题词 |
| `topic_embedding` | BLOB | topic 向量 |
| `ref_count` | INTEGER | 对话检索命中次数；`NULL` 表示升级前遗留条 |
| `pinned` | INTEGER | 1=用户勾选永久保留，整理删除时跳过 |

**旧库迁移**：启动时 `ALTER TABLE` 补 `ref_count`、`pinned`；已有行 `ref_count` 保持 `NULL`（遗留保护），`pinned` 默认为 0。新写入 `ref_count=0`。

**`ref_count` 语义**

| 值 | 含义 |
|----|------|
| `NULL` | 升级前遗留，默认不进整理删除候选 |
| `0` | 升级后写入且检索从未命中 |
| `≥1` | 曾在对话检索中命中 |

### 3.2 检索与合并

- **双路检索**：向量路 `1.2×语义 + 0.3×时间衰减`（半衰期 30 天，top 5）+ 近 7 日按 `updated_at` 新近路（top 3）；按 id 去重合并为 top 5；`pinned` 条目向量路 +0.1
- **引用强化**：最终入选条 `ref_count = COALESCE(ref_count,0)+1`，`updated_at` 刷新
- **去重**：content 相似度 > 0.92 则更新
- **写入时合并**：同 topic 簇达 5 的倍数时 LLM 合并（与聊天同模型），保留最早 `created_at`
- **手动整理**（设置页）：预览后合并同 topic 簇（≥2 条）、删除重复/闲置条；`pinned=1` 不删；`ref_count=0` 且闲置 ≥90 天可删；遗留条（`ref_count IS NULL`）默认不删
