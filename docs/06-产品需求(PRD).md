# 产品需求文档（PRD）— FGO 因陀罗桌宠

> 从根目录 `PRD.md` 迁入并纳入文档体系。产品细节以本文为准。

## 1. 产品概述

- **产品名称**：FGO 因陀罗桌面宠物（Indra Desktop Pet）
- **目标用户**：FGO / 因陀罗同好，愿意自行配置 LLM/视觉 API 与基础设置，并可能分享给同好使用。
- **核心价值**：以 FGO 中 Lancer 因陀罗的口吻进行陪伴式对话，并可定时对用户屏幕内容进行吐槽/评论，营造「神王在桌面上陪你」的沉浸感。

---

## 2. 用户画像与使用场景

- **用户画像**：熟悉 FGO 或印度神话，对因陀罗角色有认同感；具备基本的「填 API、保存设置」能力；希望桌面上有一个可互动、会说话的陪伴角色。
- **典型使用场景（高层）**：
  - 启动程序 → 桌宠出现在桌面指定位置，可拖拽、缩放。
  - 双击立绘 → 打开聊天窗口，与因陀罗文字对话（需已配置 LLM API）。
  - 通过托盘或右键打开设置 → 配置 LLM/视觉 API、屏幕观察开关与间隔、用户称呼等。
  - 开启屏幕观察 → 按设定间隔截图并生成评论，以临时气泡形式展示。

---

## 3. 已实现功能（现状清单）

### 3.1 基础交互

- 桌面透明无边框窗口，始终置顶，支持鼠标拖拽移动与缩放。
- 系统托盘图标与右键菜单：显示/隐藏桌宠、打开设置、退出等。
- 双击立绘打开气泡式聊天窗口：可输入文字发送，接收因陀罗口吻的回复；支持根据回复情绪切换表情/Emoji。

### 3.2 智能对话与知识

- LLM 对话：支持 OpenAI 兼容 API（如 DeepSeek、SiliconFlow 等），可配置 base_url、api_key、model、temperature、max_tokens、history_rounds。
- **LLM 回复 JSON 结构化**：聊天时优先要求模型只输出一个 JSON 对象（reply、emotion、memory_to_save、favorability_delta）；解析失败时回退到原有情绪标签剥离与幻觉剔除；空回复时以红色临时气泡提示。
- RAG 知识库：内置 lore（摩诃婆罗多分卷、FGO 剧情与角色资料）与 style（语气/风格文本）双索引，对话与屏幕评论均会检索相关知识以增强口吻与设定一致性。
- 本地向量嵌入：使用 `gte-multilingual-base` 离线运行，无需联网即可完成检索。
- **长期记忆（可选）**：设置页可开启「长期记忆」；开启后对话前会按**混合评分**（语义相似度 + 时间衰减，半衰期 30 天）检索已存储记忆并注入 system，LLM 可在 JSON 中返回 `memory_to_save` 将用户偏好等重要信息写入；记忆存于 SQLite（config/user_memory.db），支持去重与冲突更新；同主题合并时保留簇内最早的创建时间；设置页「记忆管理」标签可查看列表、单条删除、清空全部（二次确认）。

### 3.3 屏幕观察与评论

- 定时屏幕截图（可配置开关与间隔），截图经视觉模型（如 Qwen-VL）生成文字描述后，由 LLM 生成带情绪标签的评论，以临时气泡形式展示。
- 截图本地暂存数量可配置（如仅保留最近 N 张），不长期持久化。

### 3.4 配置与数据

- 唯一持久化配置：`config/settings.json`，涵盖桌宠名称/缩放/字体、行为（闲置间隔、屏幕观察开关与间隔、临时气泡时长、**长期记忆开关**）、用户称呼、LLM 与视觉 API 等。设置保存后通过信号热更新，无需重启。
- **开发环境**：项目根目录 `.env` 可覆盖 API 密钥等敏感项，不提交 Git。
- 长期记忆数据：`config/user_memory.db`（SQLite），仅在开启长期记忆时读写；用户可在设置页「记忆管理」中删除单条或清空全部。

## 7. 非功能需求（简要）

- **平台**：Windows 10/11，Python 3.10+。
